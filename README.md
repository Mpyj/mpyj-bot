🎮 Mpyj Game Bot

A Telegram-based gaming project built around a custom wallet, token and blockchain system.

The project combines a Telegram Bot, an in-project Wallet, a custom Token, and a Blockchain layer to create a simple competitive gaming experience for friends and family.

«🪙 Important: The project's token is designed only as an in-game currency. It has no intended monetary or investment value.»

---

✨ What is Mpyj Game Bot?

Mpyj Game Bot is a Telegram-based gaming system where users can:

- 🎮 Participate in games and competitions
- 👛 Create and manage their own Wallet
- 🪙 Receive and use project tokens
- 🏆 Compete with other players
- 📊 Track their balance and progress

The goal is to create a simple and fun way to bring competition into groups of friends and family.

---

🧩 Project Components

🤖 Telegram Bot

The main interface of the project.

Users interact with the system directly through Telegram without needing to install a separate application.

Bot: @crypppttttoooobot

👛 Wallet

Each user can create and manage their own project wallet.

The wallet is used to:

- View token balance
- Receive tokens
- Manage the user's in-project assets
- Interact with the game's token system

🪙 Project Token

The project has a dedicated token used as the in-game currency.

Total supply: 10,000 tokens

The token is intended for gameplay and competition only.

It is not designed as an investment, payment currency, or financial asset.

⛓️ Blockchain

The project includes its own blockchain-related infrastructure for handling the token system.

The blockchain layer allows the project to manage token-related operations rather than treating the token as simple database points.
